# 🧸 More Plushies (Build 41 Legacy)

**Because the apocalypse is better with a plushie.**  
This mod adds a variety of plush toys to Project Zomboid, perfect for RP, cozy base decorations, or a touch of whimsy in a bleak world.

This is the **final release for Build 41**, preserved for multiplayer compatibility and legacy servers.

> ⚠️ Please do not reupload or include this mod in modpacks without permission from the creator.

---

## 🧸 Features

- Adds several collectible plushies to the game world
- Great for RP, decoration, or morale-boosting props
- No gameplay advantages — purely aesthetic and adorable

---

## ✅ Compatibility

- ✔️ Compatible with **Project Zomboid Build 41**
- ❌ Not updated for Build 42 (which may affect item placement and object systems)

> A Build 42-compatible version will be maintained on the `main` branch of this repo.

---

## 💾 Manual Installation

1. Download the Build 41 release:  
   👉 [Release vB41.0](https://github.com/RHay6868/pz-mods-more-plushies/releases/tag/vB41.0)  
   Or [Download ZIP directly](https://github.com/RHay6868/pz-mods-more-plushies/archive/refs/tags/vB41.0.zip)

2. Extract the folder to your mods directory:

C:\Users\YourUsername\Zomboid\mods\

3. Launch the game and enable the mod in the **Mods** menu

Plushies can be found out in the world, adding charm to survivor bases or RP scenarios.

Build 42 support will likely include updates for how plushies are rendered, placed, or displayed in-game.
